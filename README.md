## Importing availabilities
Menu option 5 imports availabilities from a CSV file. A sample file is included. Use the following when asked for the path:
`sample-availabilities.csv`

## Database
`data/app.db` is created automatically on first run and is not tracked in git. When the database is empty, the app fills it with sample patients, services, resources, professionals and availabilities (the availabilities come from `seed-availabilities.csv`). To start from scratch, delete `data/app.db`.
